- **Lead:** COP31 COLLAPSES — the Antalya pact rejected, no deal adopted. First COP failure since Copenhagen 2009.
- **Top stories:** 186 drones over Ukraine, Mecca missile intercepted 01:42, Hamas seeks emergency talks, Cikande 34 unaccounted, Hong Kong 98.79% turnout, India 720/9, Verstappen wins Las Vegas.

## Entry

`main.py` (Python 3.13, standard library only, no network) copies the shipped `entry.png` to `/output/entry.png`. The image is rendered from `frontpage.html` (1024×1024, ≤1 MiB).
